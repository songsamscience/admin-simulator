# 체험용 Admin 실습 사이트

학교 관리자 선생님 연수용으로 만든 **관리 콘솔 모의 체험 사이트**입니다. 제작: 송쌤과학

- 바로 열기: https://songsamscience.github.io/admin-simulator/
- 연수용 모의 화면이라 **실제 관리 콘솔과 화면·문구·동작이 다를 수 있습니다.**
- 학교명(디지털튜터학교)·도메인(dtutor.example, 예시용 예약 도메인)·사용자 이름·학번·비밀번호 등 **모든 개인정보는 가상**입니다.
- 실제 Google 계정과 연결되지 않으며, 입력한 내용은 쓰는 사람의 브라우저(localStorage)에만 저장됩니다. 실제 비밀번호나 학생 정보를 입력하지 마세요.
- Google 및 관련 서비스와 무관한 비공식 교육 자료입니다. 로고·상표 그림은 쓰지 않았고, 메뉴 이름은 실습 안내를 위해 적었습니다.

## 실습 미션 (차례로 열림)

| 묶음 | 미션 |
|---|---|
| 계정 관리 | 1. 새 학생 계정 만들기(가명) · 2. 비밀번호 재설정 · 3. 전출 교사 삭제 + 데이터 이전 · 4. CSV로 30명 일괄 추가 |
| 유해 사이트 차단 | 5. 시크릿 모드 차단 · 6. URL 차단 · 7. 세이프서치·YouTube 제한 모드 · 8. 세이프 브라우징 강화 + SafeSites 확인 |
| 앱·저장용량 | 9. Canva 관리자 설치 · 10. 학생 저장용량 한도 10 GB |
| 보너스 | 삭제한 사용자 복원 · 오류 있는 CSV 다루기 · 로그인 제한(학교 계정만) |

오른쪽 「실습 미션」에서 [따라하기]를 누르면 눌러야 할 곳이 노랗게 반짝이고, 화면 아래 안내 띠에 단계 설명이 나옵니다.
